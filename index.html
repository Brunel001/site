How we test

  • Every task runs against a disposable copy of the system, reset to the same starting data before each run.
  • Every task runs several times, because one run can look like success while five show the pattern.
  • Results are checked in the system's database, not judged from screenshots.
  • A person does each task by hand once, so the agent's effort can be compared with a human's.

The test case format is open: github.com/Brunel001/cases-format.
