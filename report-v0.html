Method

  • Each task runs against a disposable copy of an open-source system (Odoo 17, osTicket), reset to the same starting data before every run.
  • Every task runs k times. pass@1 is the share of all runs that passed; pass^k is the share of tasks that passed every time. The 95% range is a Wilson interval on pass^k.
  • Results are checked in the database, not on screen; forbidden screens (settings, admin) fail a run even if the result is right.
  • A person did every task by hand once; their action count is shown for comparison.
  • Native dropdown lists are drawn inside the page so the agent can see them in screenshots.
  • Costs are estimated from token counts and list prices; small tasks, so ranges are wide.
